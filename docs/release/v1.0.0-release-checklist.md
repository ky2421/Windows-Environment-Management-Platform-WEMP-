1. `scripts/build.ps1 -Configuration Release`（构建 + 276 测试全绿）
2. `scripts/publish.ps1 -SelfContained`（自包含发布到 `dist/wemp`）
3. 打包脚本产出 `WEMP-1.0.0-setup.exe`（或 MSI）
4. 新装验证：全新机器安装 → 首次启动 → 数据库迁移 → 模块加载（对照启动日志）
5. 卸载验证：卸载程序执行 → 检查 %LOCALAPPDATA%\WEMP、注册表残留
6. 提交 `v1.0.0` 标签 + GitHub Release 发布说明
